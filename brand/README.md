# SoftControl brand kit

Colors: Navy #16233B · Ink #0F1A2D · Brass #A88A55 · Stone #F1EEE7
Fonts: Bodoni Moda (headings, wordmark) · Manrope (text) · IBM Plex Mono (labels) — all free on Google Fonts.

- logo/ — horizontal and stacked lockups (color, reversed, mono black/white), mark only. SVG text is outlined, so no font install is needed. PNG @4x for documents.
- favicon/ — favicon.ico (16/32/48), favicon.svg, simplified 16px version, apple-touch-icon, Android icons, maskable icon, site.webmanifest, HEAD-SNIPPET.html.
- app-icons/ — 1024 master (rounded, full-bleed for iOS, maskable for Android), iOS and Android launcher sizes.
- The website itself is the React project in the parent folder.

The contact form sends requests to Telegram through `api/contact.js` in the parent folder.
